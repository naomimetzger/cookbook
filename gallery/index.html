Before you start

What you need

Claude Code, Python 3 and ffmpeg. They work on Mac, Windows and Linux. Each recipe checks for them first and offers to install anything that's missing.

To check yourself, run this inside a recipe's folder:

python3 scripts/check_setup.py

On Windows, type python instead of python3. It lists anything missing and the install command for your computer.

Add a recipe

Every recipe is one folder. Copy the ones you want into your Claude Code skills folder: .claude/skills in your home folder, or in your project to keep it to one project.

Use it

Pick your options on a card, copy the prompt, paste it into Claude Code and put in your video's file name. You get a still to check before anything renders.

This page opens straight from the folder, with no setup. Double-click gallery/index.html.
